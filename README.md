# to-achieve-achievements

Repositório criado para conquistar insígnias (achievements) do perfil do GitHub.

## Insígnias e como conquistar

| Insígnia | Como conquistar |
| --- | --- |
| Pull Shark | Ter pull requests mergeados (2 para o nível base, 16 para bronze, 128 para prata, 1024 para ouro) |
| Quickdraw | Fechar uma issue ou PR em até 5 minutos após abrir |
| YOLO | Mergear um PR sem revisão |
| Pair Extraordinaire | Mergear um PR com um co-autor (`Co-authored-by`) |
| Galaxy Brain | Ter respostas marcadas como aceitas em Discussions |
| Starstruck | Ter um repositório com estrelas |
| Arctic Code Vault Contributor | Insígnia histórica (2020), não disponível mais |
| Public Sponsor | Patrocinar alguém via GitHub Sponsors |
| Open Sourcerer | Ter PRs mergeados em repositórios open source |

## Como usar este repositório

Os PRs de exemplo ficam em branches `achievement/*`, abertos e mergeados a partir daqui.
